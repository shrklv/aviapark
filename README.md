# Авиапарк — расчёт дозаправки в точке B

Решение задания «Авиапарк» на C++ (тема: массивы).

## Условие

В парке два самолёта. У каждого — свой бак и свой расход топлива в
зависимости от веса груза:

| Самолёт | Бак | Груз | Расход, л/км | Временный бак |
|---|---|---|---|---|
| №1 | 300 л | до 750 / 1500 / 2000 кг | 1 / 4 / 7 | нет |
| №2 | 1000 л | до 1000 / 2000 / 3000 кг | 2 / 4 / 6 | 100 л (крепится в A) |

Маршрут: **A → B → C**. Пользователь выбирает самолёт, вводит вес груза и
расстояния A-B и B-C. Программа считает, сколько топлива **минимально**
дозаправить в точке B, чтобы долететь до C. Если какой-то участок не
преодолеть — выводит сообщение о невозможности.

## Модель решения

Самолёт вылетает из A с полными баками: основным и временным (если он есть).

1. **Расход** определяется по весу груза и не меняется на всём маршруте.
2. **Участок A-B**: временный бак расходуется **первым**, потом основной.
   Это важно: в точке B дозаправить можно только основной бак, а
   временный там ни дозаправить, ни заменить нельзя. Значит, выгодно
   выжигать временный бак первым, чтобы к B основной бак остался
   максимально полным.
3. **В точке B** в основном баке остаётся `mainLeft` литров. Долить нужно
   столько, сколько не хватает до `needBC`; если бака хватает — дозаправка
   не нужна (0 л).
4. **Проверки невозможности**:
   - груз тяжелее максимального → самолёт не поднимает;
   - `needAB > бак + временный бак` → не долететь до B;
   - `needBC > основной бак` → из B до C не долететь (в баке больше не влезет).

Формулы:

```
needAB   = rate * distAB
needBC   = rate * distBC
fromMain = max(0, needAB - drop)
mainLeft = tank - fromMain
refuel   = max(0, needBC - mainLeft)
```

## Где здесь массивы

Характеристики самолётов — это таблица «самолёт × ступень груза», поэтому
хранятся в **двумерных массивах**, а не в наборе отдельных переменных:

```cpp
const double loadLimit[PLANES][TIERS] = { {750, 1500, 2000},
                                           {1000, 2000, 3000} };
const double fuelRate[PLANES][TIERS]  = { {1, 4, 7},
                                           {2, 4, 6} };
```

Поиск нужной ступени — обычный цикл по массиву, без цепочки `if`:

```cpp
int findTier(int plane, double cargo) {
    for (int i = 0; i < TIERS; i++) {
        if (cargo <= loadLimit[plane][i]) {
            return i;
        }
    }
    return -1;
}
```

Ёмкости баков — одномерные массивы: `tankCapacity[PLANES]`,
`dropTankCapacity[PLANES]`.

Если временный бак нужен и первому самолёту, достаточно поменять
`dropTankCapacity[0]` с `0.0` на `100.0` — больше ни строчки править не надо.

## Сборка и запуск

```bash
cmake -B build
cmake --build build
./build/aviapark
```

Или просто в CLion: File → Open → выбрать папку проекта → Run.

Требуется компилятор с поддержкой C++20 (GCC 10+, Clang 10+, MSVC 2019+).

## Примеры

Самолёт №2, груз 500 кг, A-B = 400 км, B-C = 300 км:

```
Расход топлива: 2.0 л/км
Участок A-B требует: 800.0 л
Участок B-C требует: 600.0 л
На A-B израсходовано: 100.0 л из временного бака, 700.0 л из основного
В пункте B в основном баке осталось: 300.0 л
Минимальная дозаправка в пункте B: 300.0 л
```

Самолёт №1, груз 1000 кг, A-B = 50 км, B-C = 100 км — до C не долететь:

```
Невозможно преодолеть расстояние B-C: нужно 400.0 л, а в основной бак помещается максимум 300.0 л
```
